One line of awkward small talk that one robot says to another while they ride an elevator together, for the [Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) bounty on make.fun.

## The line

> Your proximity sensor keeps apologizing to my proximity sensor, and we still have eleven floors to go.

102 characters, one line, no trailing newline.

## How it works

`main.py` (Python 3.13, standard library only) validates the line against the bounty gate — 1 to 200 characters, not only whitespace, a single line, no control characters — then writes it to `/output/entry.txt`. No network, no model calls, no clock, no randomness, no file reads outside the repository.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt`. Use `--out <dir>` to write elsewhere (for local testing).
